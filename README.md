# End to End Marketing Campaign Performance Analysis Project by MySQL and Excel

## Overview

This project analyzes over **165,000 marketing campaigns** from three leading Indian beauty brands:

- Nykaa
- Purplle
- Tira Beauty

The objective is to evaluate marketing effectiveness across different campaign types, customer segments, communication channels, and time periods in order to identify opportunities for improving marketing ROI and budget allocation.

## Business Questions

This analysis answers several key business questions:

- Which brand generates the highest marketing ROI?
- Which marketing channel produces the best return?
- Which campaign type drives the highest revenue?
- Which customer segment converts the best?
- Which months and quarters perform the strongest?
- How efficient is the marketing funnel from Impressions → Clicks → Leads → Conversions?
- Which campaigns should receive more budget?
- Which campaigns should be discontinued?

## Project Workflow

Cleaning data (MySQL) -> EDA (MySQL) -> Connect to Excel (Power Query) -> Preparation data -> Visualization Dashboard

## Recommendations

Potential actions include:
